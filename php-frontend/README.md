# ตัวมิเรอร์หน้าเว็บ (วางบนโฮสต์ spsccoop.com)

PHP ตัวเล็ก ๆ ที่ทำหน้าที่เดียว: **ดึงหน้าเว็บที่หลังบ้านสร้างเสร็จแล้วมาเก็บไว้ แล้วเสิร์ฟจากของที่เก็บ**
ไม่ได้วาดหน้าเว็บเอง จึงไม่ต้องเขียนหน้าตาเว็บซ้ำสองชุด — ของใหม่ที่เพิ่มในหลังบ้านตามมาเองทั้งหมด

```
สมาชิก → www.spsccoop.com (PHP ตัวนี้)
              ├─ มีในแคชและยังสด      → เสิร์ฟทันที ไม่แตะหลังบ้าน
              ├─ หมดอายุ              → ดึงของใหม่จากหลังบ้าน แล้วเก็บทับ
              └─ หลังบ้านดับ/เน็ตหลุด  → เสิร์ฟของเก่าที่เก็บไว้ (เว็บไม่ล่มตาม)
```

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.php` | ประตูหน้าเว็บ — ทุกคำขอเข้าที่นี่ |
| `lib/mirror.php` | ตัวจัดการแคช/ดึงข้อมูล/ส่งไฟล์ (รองรับขอเป็นช่วงสำหรับ PDF) |
| `purge.php` | ล้างแคชหน้าที่เพิ่งแก้ — หลังบ้านเรียกหลังกดบันทึก |
| `warm.php` | อุ่นแคชทุกหน้า ตั้ง cron รันคืนละครั้ง |
| `offline.html` | หน้าที่แสดงเมื่อหลังบ้านดับ *และ* ไม่เคยมีของในแคชเลย |
| `config.sample.php` | ตัวอย่างค่าตั้ง — ก๊อปเป็น `config.php` แล้วแก้ |
| `router-dev.php` | ใช้ตอนทดสอบในเครื่องเท่านั้น **ไม่ต้องอัปขึ้นโฮสต์** |

## วิธีติดตั้งบนโฮสต์

1. อัปทุกไฟล์ (ยกเว้น `router-dev.php`) ขึ้นโฟลเดอร์เว็บของโดเมน
2. ก๊อป `config.sample.php` เป็น `config.php` แล้วแก้ 3 ค่า
   - `backend` = ที่อยู่หลังบ้าน (เช่น `https://coopsmile.org`)
   - `purge_token` = รหัสยาว ๆ ตั้งเอง (ต้องตรงกับที่ตั้งในหลังบ้าน)
   - `cache_dir` = ปล่อยค่าเดิมได้ แค่ให้โฟลเดอร์ `cache/` เขียนได้ (755 หรือ 775)
3. อุ่นแคชครั้งแรก: `php warm.php --force`
4. ตั้ง cron วันละครั้ง (ตี 3): `php /path/to/warm.php`

## ข้อควรรู้

- `/admin`, `/api/admin`, `/api/auth` ถูกปิดตายที่ตัวนี้ — หลังบ้านเข้าได้ทางโดเมนหลังบ้านเท่านั้น
  (หลังบ้านล็อกด้วยชื่อโดเมนอยู่แล้ว ตรงนี้คือกันชั้นที่สอง)
- ไฟล์ PDF/รูป/ไฟล์ประกอบเว็บ เก็บแคชยาว 7 วัน · หน้าเว็บ 5 นาที
- แคชกินพื้นที่ประมาณ 340 MB เมื่อเก็บครบทุกหน้าและทุกไฟล์แนบ
- ต้องมี `curl` ใน PHP (โฮสต์ทั่วไปมีอยู่แล้ว) และ PHP 8.0 ขึ้นไป

## ทดสอบมาแล้ว (บนเครื่องพัฒนา ต่อกับหลังบ้านจริง)

| กรณี | ผล |
|---|---|
| เปิดหน้าแรกครั้งแรก | 200 · `X-Mirror: miss` (ไปดึงจากหลังบ้าน) |
| เปิดซ้ำ | 200 · `X-Mirror: hit` (จากแคช ไม่แตะหลังบ้าน) |
| **ปิดหลังบ้านแล้วเปิดหน้าที่เคยเข้า** | **200 · `X-Mirror: stale` — เว็บยังใช้ได้** |
| ปิดหลังบ้าน + หน้าที่ไม่เคยเข้า | 503 + หน้าแจ้งปรับปรุง |
| `/admin`, `/api/admin`, `/api/auth` | 404 ทุกอัน |
| ไฟล์ PDF | 200 · ขอเป็นช่วง (Range) ได้ 206 ตัวอ่าน E-Book จึงทำงานปกติ |
| อุ่นแคชทั้งเว็บ | 23 หน้า สำเร็จทั้งหมด · แคชรวม 1.7 MB (ยังไม่รวมไฟล์แนบ) |
| เปิด `config.php` / `lib/*.php` ตรง ๆ | 404 |
| ล้างแคชด้วยรหัสถูก/ผิด | สำเร็จ / 403 |
