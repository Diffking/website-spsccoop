# ตั้ง Google Search Console ให้ www.spsccoop.com

เครื่องมือฟรีของกูเกิล ใช้บอกกูเกิลว่าเว็บเรามีหน้าอะไร และสั่งลบที่อยู่เก่าที่ไม่อยากให้โผล่
ในผลค้นหา — เร็วกว่านั่งรอให้กูเกิลกลับมาอ่านเอง (ปกติ 1–4 สัปดาห์)

ทำครั้งเดียวจบ ใช้บัญชีกูเกิลอะไรก็ได้ที่สหกรณ์ดูแลอยู่ (แนะนำอีเมลกลางของสหกรณ์
ไม่ใช่อีเมลส่วนตัวของเจ้าหน้าที่คนใดคนหนึ่ง เผื่อวันหน้าเปลี่ยนคนดูแล)

---

## 1. เพิ่มเว็บเข้าระบบ

เปิด <https://search.google.com/search-console> แล้วเข้าสู่ระบบ

กดเพิ่มเว็บ จะมีให้เลือกสองแบบ — **เลือกแบบขวา "คำนำหน้า URL"**

| แบบ | พิสูจน์ความเป็นเจ้าของยังไง | เหมาะกับเรา |
|---|---|---|
| โดเมน (Domain) | ต้องไปเพิ่มระเบียน TXT ใน DNS | ยุ่งกว่า ข้ามไปก่อนได้ |
| **คำนำหน้า URL (URL prefix)** | อัปไฟล์เดียวขึ้นโฮสต์ | **ใช้อันนี้** |

กรอกให้ตรงเป๊ะ (มี `https://` และ `www` และ `/` ปิดท้าย):

```
https://www.spsccoop.com/
```

## 2. พิสูจน์ว่าเป็นเจ้าของเว็บ

กูเกิลจะให้ดาวน์โหลดไฟล์ชื่อประมาณ `google1a2b3c4d5e6f.html`

**เอาไฟล์นั้นวางไว้ที่รากของเว็บ** — โฟลเดอร์เดียวกับ `index.php` บนโฮสต์:

```
/domains/spsccoop.com/public_html/google1a2b3c4d5e6f.html
```

อัปด้วย File Manager ใน cPanel หรือ WinSCP ก็ได้ (ไฟล์เดียว ไม่ทริกไฟร์วอลล์)

> กฎใน `.htaccess` ของเราส่งทุกคำขอเข้า `index.php` **ยกเว้นไฟล์ที่มีอยู่จริง** —
> ไฟล์พิสูจน์ตัวตนจึงเปิดได้ตามปกติ ไม่ต้องแก้อะไรเพิ่ม

เช็คก่อนกดยืนยันว่าเปิดขึ้นจริง: `https://www.spsccoop.com/googleXXXX.html`
แล้วค่อยกดปุ่ม "ยืนยัน" ในหน้าเว็บของกูเกิล

**ห้ามลบไฟล์นั้นทิ้ง** — กูเกิลกลับมาเช็กเป็นระยะ ลบแล้วสิทธิ์หลุด

## 3. ส่ง sitemap

เมนูซ้าย → **Sitemaps** → ช่อง "เพิ่ม sitemap ใหม่" พิมพ์:

```
sitemap.xml
```

กดส่ง แล้วรอสักครู่ สถานะควรขึ้น "สำเร็จ"

ตอนนี้ sitemap ของเรามี **ที่อยู่เดียวคือหน้าแรก** ซึ่งถูกต้องแล้ว เพราะตั้งไว้ว่า
ให้ผลค้นหาโชว์เฉพาะหน้าแรก (ดูเมนู SEO ในหลังบ้าน)

## 4. เร่งให้กูเกิลมาอ่านหน้าแรกใหม่

เมนูบน → ช่องค้นหา **"ตรวจสอบ URL"** → วาง `https://www.spsccoop.com/`
→ กด **"ขอจัดทำดัชนี" (Request Indexing)**

ปกติเข้าคิวไม่กี่ชั่วโมงถึงหนึ่งวัน

## 5. ลบที่อยู่เก่าที่ไม่อยากให้โผล่

เมนูซ้าย → **การนำออก (Removals)** → **คำขอใหม่**

- เลือก **"นำ URL ทั้งหมดที่มีคำนำหน้านี้ออกชั่วคราว"**
- ใส่ที่อยู่ของหมวดที่ไม่ต้องการ เช่น `https://www.spsccoop.com/about/`

มีผลภายในไม่กี่ชั่วโมง แต่เป็นการซ่อน **ชั่วคราว 6 เดือน** — ตัวที่ทำให้หายถาวรคือป้าย
`noindex` ที่เว็บเราติดไว้ให้ทุกหน้าแล้ว การนำออกชั่วคราวแค่ทำให้หายเร็วขึ้นระหว่างรอ

## สิ่งที่จะเห็นในรายงาน — ไม่ใช่ข้อผิดพลาด

| ข้อความ | แปลว่า |
|---|---|
| "ยกเว้นโดยแท็ก noindex" ขึ้นเป็นสิบ ๆ หน้า | **ถูกต้องแล้ว** เราตั้งใจให้เก็บเฉพาะหน้าแรก |
| "หน้าที่จัดทำดัชนี: 1" | ถูกต้อง — มีหน้าแรกหน้าเดียวที่ให้เก็บ |
| spsccoop.org ไม่โผล่ในผลค้นหา | ถูกต้อง เป็นโดเมนสำรอง ตั้งห้ามเก็บไว้ทั้งเว็บ |

## ถ้าวันหนึ่งอยากให้ทุกหน้าขึ้นในผลค้นหา

หลังบ้าน → เมนู **SEO** → "ให้เข้าอ่านได้แค่ไหน" → เลือก **ทุกหน้า** → บันทึก
แล้วกลับมาส่ง sitemap ใหม่อีกครั้ง (จะมีที่อยู่ครบทุกหน้าให้เอง)
