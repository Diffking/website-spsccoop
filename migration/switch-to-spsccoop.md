## ทำไมต้องย้ายเนมเซิร์ฟเวอร์ ไม่ใช่แค่แก้ระเบียน DNS

โดเมน spsccoop.com ใช้เนมเซิร์ฟเวอร์ `ns77/ns78.hostinglotus.net` ซึ่งอยู่เครื่องเดียวกับ
โฮสต์ที่ล่มอยู่ตอนนี้ — แก้ระเบียน DNS ที่นั่นไม่ได้จนกว่าเครื่องจะกลับมา
ย้ายเนมเซิร์ฟเวอร์ไป Cloudflare ทำที่ **ผู้รับจดโดเมน** จึงไม่ต้องรอโฮสต์

## ขั้นตอน (ทำในบัญชีเจ้าของเว็บ)

1. **เพิ่มโดเมนเข้า Cloudflare** — dash.cloudflare.com → Add a site → `spsccoop.com` → แผนฟรี
   Cloudflare จะดึงระเบียน DNS เดิมมาให้ ตรวจให้ครบก่อนไปต่อ
   (สำคัญ: ระเบียนของ mail / อีเมล และโดเมนย่อยอื่น ๆ เช่น api · loan · officer ·
   committee · ag — ต้องมีครบ ไม่งั้นระบบพวกนั้นล่มตามไปด้วย)

2. **เปลี่ยนเนมเซิร์ฟเวอร์ที่ผู้รับจดโดเมน** เป็นสองตัวที่ Cloudflare ให้มา
   รอ 5 นาที – 24 ชั่วโมงให้มีผลทั่วโลก

3. **เพิ่มชื่อโดเมนเข้าอุโมงค์** — Cloudflare → Zero Trust → Networks → Tunnels →
   อุโมงค์ที่ใช้อยู่ → Public hostname → Add
   - Subdomain: `www`
   - Domain: `spsccoop.com`
   - Service: `HTTP` → `web:3000`
   (ถ้าอยากให้ `spsccoop.com` เฉย ๆ เข้าได้ด้วย ให้เพิ่มอีกรายการโดยเว้น Subdomain ว่าง)

4. **บอกให้ผมสลับที่อยู่เว็บในระบบ** — เปลี่ยน SEO siteUrl เป็น `https://www.spsccoop.com`
   แล้ว build ใหม่ (ใช้เวลาไม่เกิน 5 นาที เว็บสะดุด 1–2 นาที)

## ตรวจว่าพร้อมหรือยัง

```bash
bash migration/check-domain.sh
```

## หลังย้ายเสร็จ

- `www.spsccoop.com` = หน้าเว็บสาธารณะ (มาจากเครื่องนี้)
- `spsccoop.org` = หลังบ้านสำหรับเจ้าหน้าที่
- โฮสต์ hostinglotus ไม่ถูกใช้กับเว็บอีกเลย — หน้าแจ้งปรับปรุงที่อัปไว้จะไม่มีใครเห็น
- ส่งแผนผังเว็บใหม่ให้กูเกิลที่ `https://www.spsccoop.com/sitemap.xml`
