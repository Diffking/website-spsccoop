# ทางเข้าหลังบ้านที่ admin.coopsmile.org

เดิมเจ้าหน้าที่เข้าหลังบ้านที่ `coopsmile.org/admin` ซึ่งเป็นโดเมนเดียวกับที่ตัวมิเรอร์
ใช้ดึงหน้าเว็บไปให้สมาชิก เอกสารนี้คือวิธีย้ายทางเข้าไปอยู่ที่ซับโดเมนของตัวเอง

```
สมาชิก      → www.spsccoop.com ──ดึงหน้าเว็บ──→ coopsmile.org ─┐
เจ้าหน้าที่ → admin.coopsmile.org ───────────────────────────────┴─→ เครื่องนี้ (web:3000)
```

ทั้งสองซับโดเมนวิ่งเข้าเครื่องเดียวกันผ่าน Cloudflare Tunnel ตัวเดิม ไม่ต้องเปิดพอร์ต
ไม่ต้องมีไอพีจริง และไม่ต้องตั้ง SSL เอง (Cloudflare ออกใบรับรองให้)

## 1. เพิ่มซับโดเมนใน Cloudflare (ต้องกดในหน้าเว็บ ~2 นาที)

1. เปิด <https://one.dash.cloudflare.com> → เลือกบัญชีของสหกรณ์
2. เมนูซ้าย **Networks → Tunnels** → คลิกที่ tunnel ตัวที่รันอยู่ (ตัวที่สถานะ HEALTHY)
3. แท็บ **Public Hostname** → ปุ่ม **Add a public hostname**
4. กรอกตามนี้

   | ช่อง | ค่า |
   |---|---|
   | Subdomain | `admin` |
   | Domain | `coopsmile.org` |
   | Path | เว้นว่าง |
   | Type | `HTTP` |
   | URL | `web:3000` |

5. **Save hostname**

Cloudflare สร้าง DNS ให้เองอัตโนมัติ ไม่ต้องไปเพิ่ม record เอง
รอ 1-2 นาทีแล้วเปิด <https://admin.coopsmile.org> ได้เลย

**ไม่ต้องพิมพ์ `/admin` ต่อท้าย** — เปิดหน้าแรกของซับโดเมนนี้แล้วระบบพาไปหน้าล็อกอินให้เอง
(ตั้งไว้ที่ `ADMIN_ROOT_HOST` ใน `.env`)

> ค่า URL ต้องเป็น `web:3000` (ชื่อ service ใน docker-compose) เหมือนกับซับโดเมนเดิมที่ตั้งไว้แล้ว
> ไม่ใช่ `localhost:8030` — ตัว `cloudflared` อยู่ในเน็ตเวิร์กเดียวกับ `web` มองเห็นกันด้วยชื่อ service

## 2. ปิดทางเข้าเก่า

`.env` ตั้งไว้ให้เปิดได้ทั้งสองทางระหว่างเปลี่ยนผ่าน กันเข้าหลังบ้านไม่ได้ทั้งคู่

```env
ADMIN_HOST=admin.coopsmile.org,coopsmile.org
```

พอทางใหม่เข้าได้จริงแล้ว ให้เหลือทางเดียว

```env
ADMIN_HOST=admin.coopsmile.org
```

```bash
docker compose up -d web     # แค่รีสตาร์ต ไม่ต้อง build ใหม่
```

จากนั้น `coopsmile.org/admin` จะตอบ 404 เหมือนไม่เคยมีหน้านี้อยู่

## เรื่องที่ต้องรู้

**ยังเข้าจากเครื่องนี้ได้เสมอ** — `localhost:8030/admin` เปิดได้ตลอดไม่ว่าตั้ง `ADMIN_HOST`
เป็นอะไร เผื่อตั้งค่าผิดจะได้ไม่ล็อกตัวเองออกจากหลังบ้าน

**กูเกิลไม่เก็บซับโดเมนนี้** — `robots.txt` ตอบ `Disallow: /` ให้ทุกโดเมนที่ไม่ใช่โดเมนหลัก
(ดู `onCanonicalHost` ใน `src/lib/seo.ts`) ซับโดเมนหลังบ้านจึงถูกกันไว้อยู่แล้วโดยอัตโนมัติ

**ไม่กระทบสถิติผู้เข้าชม** — ระบบนับเฉพาะคนที่เปิด `spsccoop.com` เจ้าหน้าที่ทำงานในหลังบ้าน
ไม่ถูกนับรวม ไม่ว่าจะเข้าทางไหน

**อยากได้ชั้นกันเพิ่ม** — ที่หน้า Public Hostname เดียวกันเปิด Cloudflare Access ได้
บังคับให้ยืนยันอีเมลก่อนถึงจะเห็นหน้าล็อกอินของระบบ (ยังไม่ได้เปิดไว้)
